# 验证记录

这份文档记录题库与应用**实际做过的验证**，以及**没能验证的部分**。目的是让你知道哪些地方可以放心、哪些地方要自己再看一眼。

---

## 一、验证方式

| 环节 | 做法 |
| --- | --- |
| 命题 | 按五个知识点分卷，力学 / 电磁学 / 热学 / 光学 / 近代物理各 20 题，共 100 题 |
| **独立复核** | 每卷另派一位审题人，**只看题干与选项重新独立求解**（数值题用 Node 复算，方向判断题用 `F = qv×B` 叉乘或左/右手定则推导），再与文件里的答案键逐题比对。复核人**不允许修改文件**，只出报告 |
| **应用端到端测试** | 用 jsdom 真实执行页面脚本并模拟点击，走完 **80 项断言**：首页渲染 → 随机组卷 → 作答/判分/解析 → 成绩单 → 错题本 → 收藏 → 统计 → 题库 JSON 导入（合法与非法）→ **试卷纯文本导入**（含跨行题干、行首小数、同行选项等易错格式）→ 设置项 → 使用说明 |
| **机械审计** | 全库检查 LaTeX 残留、`如图` 类缺图引用、答案键是否都在选项中、答案字母分布是否偏集中、题干是否重复 |

复核不是「审阅 AI 的解析」，而是**让另一个模型重新把题做一遍**再对答案——这是能发现答案键错误的关键。

## 三、已修正的实质性问题

### 电磁学（3 处答案键错误 + 2 处解析错误）

| 题号 | 问题 | 修正 |
| --- | --- | --- |
| DC-011 | **答案键错误**。电子向右运动、向上偏转，要求洛伦兹力向上。由 `F = qv×B`（电子带负电，方向与 `v×B` 相反）可判磁场应**垂直纸面向外**。原答案标为 A（向里），且解析中左手定则的两处判断都判反了 | 答案 A → **C**，解析重写，并补上 `F = qv×B` 的验算 |
| DC-016 | **答案键错误**。小球下落 0.4 m、动能 4 J，重力做功 0.4 J，故电场力做功 +3.6 J；位移向下而电场力做正功 ⇒ 电场力向下；q 为正 ⇒ **电场强度方向竖直向下**。原答案标 D（大小 9×10⁴ V/m 但方向写成向上），原解析把「W电 > 0」说成「电场力向上」 | 答案 D → **A**。选项 D 保留为干扰项（数值对、方向错），解析重写并补牛顿第二定律验算 a = 100 m/s²、Ek = 4 J 自洽 |
| DC-019 | **答案键错误 + 题干信息不足**。放电时电流增大、电场能转化为磁场能、周期 T = 6.28×10⁻⁵ s 都是对的；但选项 C 断言线圈中电流「自下而上」，而「上/下」在题目未给电路图时无法唯一确定，且按标准回路画法实际是自上而下 | 选项 C 改写为不依赖图形、可明确判断正误的表述，答案 BCD → **BD**，解析重写 |
| DC-005 | 答案 C 正确，但解析末尾称末动能「变为 1.5Ek₀」，实为 **2Ek₀**（v_y = v₀，Ek = ½m(v₀²+v_y²) = mv₀² = 2Ek₀）；错项倍率也说错了 | 解析重写，难度 4 → 3 |
| DC-013 | 答案 A 在给定几何下正确，但**题干未说明 a、b 相对运动方向的位置关系**，高电势端无法唯一确定；且未定义 L、B | 题干补足「俯视时导轨南北向、导体棒东西向、a 在西、b 在东、磁场竖直向下、以速度 v 向北运动」及 B、L 定义；解析重写为电子受洛伦兹力的推法 |

### 电磁学第二轮复核补充修正

修订完成后又做了一轮独立复核，结论是 **20 题答案键全部正确**，另发现 3 处**解析中对干扰项错因的描述**不严谨、以及 2 处措辞问题，已全部修正：

| 题号 | 问题 | 修正 |
| --- | --- | --- |
| DC-005 | 解析把干扰项 D 的 4 倍误差归因于「遗漏 1/2 因子」，但遗漏 1/2 只能得到 1/2 倍（即选项 B）。4 倍实际来自把沿 v₀ 方向的位移误取为 d（用 t = d/v₀ 而不是 2d/v₀） | 归因改写为「把沿 v₀ 方向的位移当成 d」 |
| DC-015 | 解析称干扰项 5 V 是「少算了一个数量级」，实际只差 2 倍 | 改为「来自把 0.2 × 0.5 误算成 0.05 一类的算术失误」 |
| DC-018 | 解析称「用 100 kV 会得到 100 A」——实际 100 kV 得 1 A，要得 100 A 是把 10 kV 误当 1 kV；又称损耗「错成 10 kW」，而选项给的是 1 kW 与 100 kW，均不符 | 错因按 1 kV 误代重写，并说明 100 A 对应 100 kW |
| DC-007 | 解析把 D 项（R/4）笼统归入「认为 S 不变或增大了」，而 S 不变只会得到 2R | 改为「A、D 都相当于认为横截面积变大」 |
| DC-012 | 「由牛顿第三定律，铜环也会受到磁铁对它的向下的力」语义重复、配对关系没说出来 | 改写为作用力与反作用力的完整表述 |

力学分卷 **20 题答案键与解析全部复核无误**。审题人提出的均为表述建议，未构成错误：

## 四、答案字母分布的修正

复核发现部分分卷答案过度集中于 A，学生可以靠「蒙 A」得分：

| 科目 | 修正前（单选） | 修正后（单选） |
| --- | --- | --- |
| 光学 | A:10 B:2 C:2 D:1 | **A:4 B:4 C:4 D:3** |
| 电磁学 | A:8 B:2 C:4 D:1 | **A:4 B:4 C:4 D:3** |
| 全库 73 道单选 | A:29（40%） | **A:19 B:20 C:18 D:16** |

做法是**打乱选项顺序并同步更新答案**，同时把解析里按字母指代选项的写法改成按**选项内容**指代（例如「错项 7.5 m 是把 3 s 全当成运动时间」而不是「A 项 7.5 m ……」）。这样以后再次调整选项顺序，解析也不会失效。

> 请你补充新题时也尽量遵守这条：**解析里避免用 A/B/C/D 指代选项，直接写选项内容**。

构建脚本 `npm run bank` 会打印各知识点单选的答案字母分布，某个字母超过 45% 时会提示「偏集中」。

## 五、来源标注的规范化

复核同时指出：多道题标为「高考真题改编（全国卷·××）」，但题干只是通用模型，**没有可核对的年份卷别**，这个标注属于过度声称。

处理：**59 条无法核实的「真题改编」全部降级为「模拟题」**，来源文字改为「高考风格模拟题（××·××）」。最终分布：

- `模拟题` 61 题 —— 按高考模型与考法编拟，不是原题
- `自编` 39 题 —— 依教材典型模型自行命题
- `真题` 0 题、`真题改编` 0 题

并在 `tools/build-bank.mjs` 里加了长期护栏：**只要 `sourceType` 标为「真题」或「真题改编」而 `source` 里没有四位数年份，构建时就会报警**。

## 七、验证的边界（请务必了解）

1. **复核是 AI 对 AI，不是人类教师审题。** 命题者和复核者是同一类模型，可能共享同类盲点。3 处答案键错误被查出来说明复核有效，但**不能保证 100% 无错**。
2. **不在覆盖范围内的题型**：计算题、实验题、图像题（需要看图作答的题）都没有收录，题库只有 4 选项的选择题。
3. **难度标注与知识点标签是主观判断**，未经同行评审，你按自己的标准调整即可。
4. **与真实高考原题的相似度未经逐题比对。** 现有题目是按高考模型编拟的，没有与原卷做过一一对照说明。
5. **真机未测试。** 所有前端验证都是在 jsdom（Node 环境）里做的——它验证了逻辑正确、无脚本异常，但**不验证 iPhone 上的实际渲染效果**。PWA 安装、Service Worker 离线缓存也只在代码层与 http 层验证过，没有在真实 iPhone 上走过一遍。
6. **数值题的中间过程**虽然被复算过，但题目情境与数据是编拟的，若用于考试请自行核对答案与单位。

## 八、如何自己重跑这些验证

```bash
npm run bank        # 题库结构校验 + 来源诚实性检查 + 答案分布报告
npm run serve       # 本地预览（另开一个终端）
npm test            # 端到端冒烟测试（需要 serve 已在 5173 端口运行）
```

端到端测试需要 jsdom。若你的环境里没有安装，可以直接跳过——它只是开发期的自测工具，不影响应用本身运行。
